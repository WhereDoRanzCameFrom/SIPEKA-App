# 📊 SIPEKA - Dinsos PM Kalimantan Utara

**SIPEKA** (*Sistem Pelaporan dan Kinerja Anggaran*) is a web-based budget reporting and performance monitoring system developed for the **Department of Social Services and Community Empowerment (Dinsos PM) of North Kalimantan Province**.

# *The main source code of this project is stored in a private repository for security and copyright reasons.*

## 📝 About the Project

SIPEKA is designed to streamline, track, and optimize the submission, evaluation, and monitoring of budget implementation and financial performance reports. Built as a centralized web application using PHP Native connected to MySQL (phpMyAdmin), the system ensures accurate data logging, multi-level verification, and real-time performance analytics for regional social welfare programs.

---

## 🛠️ Tech Stack & Architecture

- **Core Backend:** PHP Native
- **Database:** MySQL / phpMyAdmin (Relational Database Management System)
- **Frontend User Interface:** HTML5, CSS3, JavaScript, Bootstrap
- **Web Server:** Apache / Nginx (XAMPP / Local Server / Production Hosting)

---

## 💎 Key Features

- **Dashboard & Performance Analytics:** Real-time summary of budget realization, expenditure summaries, and departmental performance metrics.
- **Budget Realization Tracking:** Log and track budget allocations vs. actual expenditures across various social welfare programs.
- **Report Submission & Verification:** Structured submission workflow for official financial and operational reports with verification levels.
- **Role-Based Access Control (RBAC):** Customized access privileges for administrative staff, reviewers, and department leaders.
- **Data Export & Reporting:** Export budget execution logs and financial summaries into structured formats (e.g., PDF/Excel) for official archiving.
- **Database Management via phpMyAdmin:** Centralized data structure for easy maintenance, exports, and database backups.
